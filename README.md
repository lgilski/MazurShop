# Ecommerce App Learning Project

This is a learning project built with Next.js and Sanity, created to practice building a modern e-commerce storefront.

## About

The app is designed to help explore web development concepts such as:

- React and Next.js for the front-end experience
- Sanity CMS for product content and image management
- Redux for cart state management
- Stripe payment integration for checkout flow
- Tailwind CSS and Styled Components for styling

## Features

The project demonstrates several e-commerce features, including:

- Product browsing and detail pages
- Search and navigation for categories and goods
- Cart management with quantity selection
- Checkout flow using Stripe
- Responsive layout for desktop and mobile
- Content managed through Sanity studio

## Tech Stack

Key technologies used in this project:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Styled Components
- Redux / Redux Toolkit
- Sanity
- Stripe
- React Hot Toast
